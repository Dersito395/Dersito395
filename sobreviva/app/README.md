# SOBREVIVA — aplicativo mobile (Flutter)

Veja o [README do projeto](../README.md) e a pasta [docs](../docs/).

```bash
flutter pub get
flutter test
flutter run
```

A biblioteca embarcada (`assets/content/essencial.json` e `assets/media/`) é gerada por
`cd ../server && npm run build:content` a partir de `../content/`. Não edite esses arquivos à mão.
